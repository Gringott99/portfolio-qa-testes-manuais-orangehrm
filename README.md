# portfolio-qa-testes-manuais-orangehrm
Projeto prático de Software QA focado na execução de testes manuais e rastreabilidade da funcionalidade de Login do OrangeHRM. Inclui mapeamento de requisitos, cenários de teste (positivos e negativos), execução de rodada de regressão, gerenciamento de evidências e modelos de relatórios de bugs.
