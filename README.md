## 🇧🇷 Português

### 📌 Sobre o Projeto
Projeto prático de Garantia de Qualidade (QA) focado na execução de testes manuais, documentação de casos de teste e rastreabilidade na funcionalidade de **Autenticação / Login** da aplicação **OrangeHRM**.

### 🎯 Objetivo
Validar o comportamento funcional e as validações do fluxo de Login..., cobrindo cenários positivos (caminho feliz) e cenários negativos (validações de erro e campos obrigatórios).

### 📂 Estrutura da Planilha de Testes
- **Resumo**: Dashboard simplificado com métricas globais da execução.
- **Requisitos**: Mapeamento das regras de negócio atreladas aos testes.
- **Cenários de Teste**: Divisão dos testes em fluxos positivos e negativos.
- **Casos de Teste**: Passos detalhados para execução, resultados esperados e obtidos.
- **Execução**: Rodada 1 — Execução de Testes Funcionais
- **Evidências**: Links diretos com imagens comprobatórias no Google Drive.
- **Bug Reports**: Modelo de reporte padronizado para rastreamento de defeitos.

### 📊 Métricas da Rodada 1 (Execução de Testes Funcionais)
- **Casos de Teste Executados:** 6
- **Passed (Passaram):** 6 (100%)
- **Failed (Falharam):** 0
- **Status da Aplicação:** Estável

### 🛠️ Ferramentas Utilizadas
- **Gerenciamento e Execução:** LibreOffice Calc / Microsoft Excel
- **Armazenamento de Evidências:** Google Drive
- **Plataforma de Teste:** OrangeHRM Demo OS

## 🇺🇸 English

### 📌 About the Project
A practical Software Quality Assurance (QA) project focused on manual test execution, test case documentation, and traceability for the **Authentication / Login** module of the **OrangeHRM** application.

### 🎯 Objective
Validate the security, usability, and functional behavior of the Login flow, covering both positive scenarios (happy path) and negative scenarios (error validations and mandatory fields).

### 📂 Test Spreadsheet Structure
- **Resumo (Summary)**: High-level dashboard with global execution metrics.
- **Requisitos (Requirements)**: Mapping business rules associated with tests.
- **Cenários de Teste (Test Scenarios)**: Categorization into positive and negative flows.
- **Casos de Teste (Test Cases)**: Step-by-step instructions, expected and actual results.
- **Execução (Execution)**: Execution logs from the first regression testing round.
- **Evidências (Evidences)**: Direct Google Drive links with screenshots.
- **Bug Reports**: Standardized bug report template for defect tracking.

### 📊 Round 1 Metrics (Regression)
- **Executed Test Cases:** 6
- **Passed:** 6 (100%)
- **Failed:** 0
- **System Status:** Stable

### 🛠️ Tools Used
- **Management & Execution:** LibreOffice Calc / Microsoft Excel
- **Evidence Storage:** Google Drive
- **Test Application:** OrangeHRM Demo OS
